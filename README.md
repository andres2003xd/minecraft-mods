# 🎮 Mis Mods de Minecraft 1.21.1

Pack personalizado de mods para Minecraft 1.21.1 con Fabric.

## ⚙️ Requisitos Previos

- **Minecraft:** 1.21.1
- **Fabric Loader:** 0.18.4 - 1.21.1

## 📦 Contenido del Pack

Este pack incluye **120 mods** que mejoran significativamente la experiencia de juego con:

- **Contenido Pokémon:** Cobblemon y extensiones afines
- **Estructuras Generadas:** Dungeons & Taverns, Incendium, Structory
- **Mejoras de Rendimiento:** Sodium, Lithium, Ferritecore
- **Calidad de Vida:** Inventario mejorado, brújula, mapas
- **Mecánicas de Juego:** Mejoras de combate, encantamientos, granjas
- **Utilidades:** Almacenamiento, configuración, debuggeo

## 🚀 Instalación

1. **Instala Fabric Loader 0.18.4 para la version 1.21.1 de minecraft** desde [fabricmc.net](https://fabricmc.net/)
3. **Copia todos los archivos .jar** de la carpeta `mods/` a `.minecraft/mods`
4. **Inicia el juego** con el perfil Fabric
